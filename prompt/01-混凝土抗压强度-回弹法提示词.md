# 混凝土抗压强度-回弹法提示词

> **统一表述规范**：构件名称统一写为「混凝土梁 / 混凝土板 / 混凝土柱 / 混凝土剪力墙 / 混凝土基础」，存在多种构件类型时统一写为「混凝土构件」；强度值保留1位小数，合格率保留1位小数；结论类型统一为「类型一（全部合格）/ 类型二（存在不合格）/ 类型三（无图纸）」；结论字段统一为「结论表述」。

## 一、任务目标

依据《回弹法检测混凝土抗压强度技术规程》JGJ/T 23-2011，对回弹法混凝土抗压强度检测数据进行统计与评定，输出**唯一**结论：存在有效批量批时采用批评定结论，否则采用单构件评定结论。

**输入**：每条记录含 `构件类型`、`轴号`（仅用于标识，不参与统计）、`设计强度等级`、`测区混凝土强度换算值`（可多个）。

**输出**：仅一个 JSON 对象，`校验概述` 中包含 `结论类型` 与 `结论表述` 两个字段。

## 二、核心计算规则

1. **单构件推定值**（用于单构件评定）
   - 测区数 n＜10 → 取该构件各测区混凝土强度换算值的最小值 `f_cu,min`。
   - 测区数 n≥10 → `f_cu,e = m_fcu − 1.645 × s_fcu`（保留1位小数）。
   - 若任一测区混凝土强度换算值 ＜10.0 MPa → 该构件推定值按 `＜10.0MPa` 处理（不合格）。
   - 合格判定：推定值 ≥ 设计强度标准值（如 C30 = 30.0 MPa）。
2. **全部构件统计**（不按楼层、不分层）
   - 总构件数、合格构件数、不合格构件数。
   - **单构件合格率** = 合格构件数 / 总构件数 × 100%（保留1位小数）。
   - 全部构件混凝土抗压强度推定值范围 = 所有构件推定值的最小值 ~ 最大值。
3. **批评定（批量统计）**
   - 按 **构件类型 + 设计强度等级** 严格分组。
   - 样本量要求：同组全部构件测区混凝土强度换算值个数 n ≥ 10。
   - 标准差超限判定：若同组强度平均值 `m_fcu`＜25.0 MPa 且标准差 `s_fcu`＞4.5 MPa，或 25.0 MPa≤`m_fcu`≤60.0 MPa 且 `s_fcu`＞5.5 MPa，则该组不能作为有效批量批，应全部按单构件评定。
   - 满足时，批评定值 `f_cu,e = m_fcu − 1.645 × s_fcu`（保留1位小数）。
   - 合格判定：`f_cu,e` ≥ 设计强度标准值。
   - 若不满足样本量要求或标准差超限，则该组无批评定值。
4. **批评定有效性判定**
   - 若输入数据中**批量批评定值（`f_cu,e`）字段为“/”、空值或 0**，表示该批不满足批评定条件，**直接判定为“不存在有效批量批”**。
   - 若存在有效批量批，则**优先采用批评定结论**，不再输出单构件评定结论。

## 三、结论生成规则

1. 若存在**任何有效批量批**（至少一个分组满足样本量要求且标准差不超限）→ 采用**批评定结论**（模板B），不输出单构件评定结论。
2. 若**不存在任何有效批量批** → 采用**单构件评定结论**（模板A）。
3. 若为**无图纸**情况（输入设计强度等级为“/”，或全部构件均无设计强度等级）→ 优先输出无图纸结论（模板C），不再区分单构件 / 批评定。

**构件名称填写规则**：仅一种构件类型时填该类型全称（如全部为梁 → 「混凝土梁」）；存在多种构件类型时统一填「混凝土构件」。

## 四、结论模板

### 模板A：单构件评定结论（仅在无有效批量批时使用）

| 情况 | 判定条件 | 结论表述 |
| :-- | :-- | :-- |
| **全部合格** | 不合格构件数 = 0 | 回弹法所检{构件}构件混凝土抗压强度推定值范围为{X.X}MPa~{Y.Y}MPa，均满足相应设计强度等级要求。 |
| **部分不合格** | 0 ＜ 不合格构件数 ＜ 总构件数 | 回弹法所抽检的{总构件数}个{构件}构件中，有{不合格数}个混凝土抗压强度推定值不满足设计要求，其余构件均满足设计要求。详见表xxx。 |
| **全部不合格** | 不合格构件数 = 总构件数 | 回弹法所抽检的全部（{总构件数}个）{构件}构件混凝土抗压强度推定值均未达到相应设计强度等级要求。 |

- 全部合格时，若存在多种设计强度等级，统一使用“相应设计强度等级要求”。

### 模板B：批评定结论（仅在存在有效批量批时使用）

| 情况 | 结论表述 |
| :-- | :-- |
| **全部批评定合格** | 回弹法所抽检{构件}构件批混凝土抗压强度推定值为{X.X}MPa~{Y.Y}MPa，满足相应设计强度等级要求。 |
| **部分批评定不合格** | 回弹法所抽检{构件}构件批混凝土抗压强度推定值为{X.X}MPa~{Y.Y}MPa，其中{不合格部位及对应值}。 |
| **全部批评定不合格** | 回弹法所抽检的全部批量检验批评定值均未达到相应设计强度等级要求。 |

- 若仅有一个有效批量批，`{X.X}~{Y.Y}` 替换为单一值 `{X.X}MPa`。
- 部分不合格时，`{不合格部位及对应值}` 格式固定为：`{分组标识1}批评定值为{Z.Z}MPa，{分组标识2}批评定值为{W.W}MPa`，逐一列出所有不合格批及其批评定值。

### 模板C：无图纸结论

若输入明确标注“无图纸”，或全部构件均无设计强度等级，则输出：

- 回弹法所检{构件}构件混凝土抗压强度推定值范围为{X.X}MPa~{Y.Y}MPa，详见表xxx。

## 五、输出 JSON 格式

```json
{
  "校验概述": {
    "总构件数": 数字,
    "合格构件数": 数字,
    "不合格构件数": 数字,
    "单构件合格率": 数字或null,
    "全部构件强度推定值范围MPa": "X.X~Y.Y",
    "设计强度等级汇总": ["C30", "C35"],
    "批评定结果": {
      "是否存在有效批量批": true,
      "批量批组数": 数字或null,
      "批评定值汇总MPa": "X.X" 或 "X.X~Y.Y" 或 null,
      "批评定是否全部合格": true 或 null,
      "不合格批量批明细": ["混凝土梁-C40: 28.5MPa", "混凝土柱-C35: 32.1MPa"] 或 null
    },
    "结论类型": "类型一/类型二/类型三",
    "结论表述": "字符串（严格套用所选模板，不含其他内容）"
  }
}
```

- 数值字段为数字类型，范围字段为字符串（如 `"32.5~45.6"`）。
- 无图纸项目：`设计强度等级汇总` 为 `[]`，`单构件合格率` 为 `null`，`批评定结果` 各字段为 `null`，`结论类型` 为“类型三”，`结论表述` 使用模板C。
- 存在有效批量批：`批评定值汇总MPa` 统一为字符串，单一值如 `"35.2"`，多个值取范围如 `"35.2~42.8"`。
- 输入中批量批评定值为“/”、空值或 0：`是否存在有效批量批` 为 `false`，批评定相关字段为 `null`，`结论表述` 使用模板A。
- 全部合格（批评定或单构件评定）→ `结论类型` 为“类型一”；存在不合格构件或不合格批 → `结论类型` 为“类型二”。

## 六、关键约束

1. **绝对禁止**输出任何明细列表（构件明细、测区明细、批量统计明细、轴号、楼层等）。
2. **结论只能有一个**：优先批评定（存在有效批量批时），否则单构件评定。
3. **单构件合格率** = 合格构件数 / 总构件数 × 100%，分母为构件数，不是测区数。
4. 批评定分组时，同组构件必须属于同一构件类型和同一设计强度等级，且标准差不得超限，否则不能作为有效批量批。
5. 结论表述中的构件名称一律使用「混凝土梁 / 混凝土板 / 混凝土柱 / 混凝土剪力墙 / 混凝土基础」，多类型时使用「混凝土构件」。
6. 纯 JSON 输出，无额外文字。
7. 若用户未提供原始数据，输出 `{"error":"请提供回弹法检测原始数据"}`。
