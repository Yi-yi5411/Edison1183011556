# 构件厚度-混凝土板提示词

> **统一表述规范**：构件名称统一写为「混凝土梁 / 混凝土板 / 混凝土柱 / 混凝土剪力墙 / 混凝土基础」，存在多种构件类型时统一写为「混凝土构件」；合格点率保留1位小数，偏差平均值保留2位小数；结论类型统一为「类型一（合格）/ 类型二（不合格）/ 类型三（无图纸）」；结论字段统一为「结论表述」；本文件结论中的构件名称与检测项目固定表述为「混凝土结构构件结构厚度」，不得改写。

## 一、任务目标

依据《混凝土结构工程施工质量验收规范》GB 50204-2015（现浇结构位置和尺寸允许偏差见表8.3.2），对混凝土结构构件结构厚度检测数据**按楼层分组**，**直接读取每条数据已有的“合格判断结果”和“实测偏差平均值”字段**，计算**测点合格点率**作为整体合格性判定依据；同时，若需输出详细统计，则另行按**三类测点**（符合规范 / 符合要求 / 不符合规范）独立统计，两者**绝对不能混淆**。

**最终输出**：一个 JSON 对象，仅含“校验概述”和“逐层校验明细”。

> **重要前提**：输入数据已完整包含“合格判断结果”（值为“符合规范”/“符合要求”/“不符合规范”）和“实测偏差平均值”（数值）字段，因此**严禁进行任何偏差计算或合格判断的二次生成**，所有统计仅依赖这两个已有字段。

## 二、核心定义（严格区分）

| 术语 | 定义 | 用途 |
| :-- | :-- | :-- |
| **测点** | 每个独立的厚度检测点，每个测点有一个“合格判断结果”和一个“实测偏差平均值”。 | **整体合格性判定**的唯一基础单元。 |
| **构件** | 每个独立混凝土板构件（如“LB1”），同一构件可能包含多个测点。 | **仅用于模板2的详细统计**，不参与整体合格判定。 |
| **符合规范（测点合格）** | 实测厚度偏差在 [h-5mm, h+10mm] 内（GB 50204-2015 表8.3.2：墙、柱、梁截面尺寸允许偏差 +10mm、-5mm），h 为设计厚度。 | 计入“测点合格点率”。 |
| **符合要求** | 实测厚度偏差＞+10mm（正偏差偏厚），无结构安全不利影响，可正常使用，但**不属于规范合格范畴**。 | 不计入合格。 |
| **不符合规范** | 实测厚度偏差＜-5mm（负偏差偏薄），可能影响结构性能和使用功能，关联 GB 50204-2015 第8.3.1条。 | 不计入合格。 |
| **测点合格点率** | = 符合规范测点数 / 总测点数 × 100%（保留1位小数） | 用于判定整体合格（≥80%为合格，依据 GB 50204-2015 第3.0.4条）。 |
| **构件合格率** | = 合格构件数 / 总构件数 × 100%（保留1位小数） | 仅用于模板2中的百分比填充。 |
| **全楼实测偏差平均值** | = Σ各测点“实测偏差平均值”字段数值 ÷ 总测点数（保留2位小数） | 用于“校验概述”及类型三的实测偏差范围。 |

## 三、结论模板及其适用规则

**整体合格性判定**：以**测点合格点率**为准，≥80% 为合格，＜80% 为不合格。

| 结论类型 | 适用条件 | 必须套用的结论表述 | 填充数据来源 |
| :-- | :-- | :-- | :-- |
| **类型一（合格）** | 有图纸，测点合格点率 ≥ 80% | 所检混凝土结构构件结构厚度实测偏差平均值合格点率为xxx%，符合《混凝土结构工程施工质量验收规范》GB 50204-2015第3.0.4条之规定。 | xxx = 测点合格点率（%） |
| **类型二（不合格）- 模板1** | 有图纸，测点合格点率 ＜ 80%，且不合格测点中“符合要求”（正偏差＞+10mm）占比 ＜ 60% | 所检混凝土结构构件结构厚度实测偏差平均值合格点率为xxx%，不符合《混凝土结构工程施工质量验收规范》GB 50204-2015第3.0.4条之规定。 | xxx = 测点合格点率（%） |
| **类型二（不合格）- 模板2** | **仅在用户明确要求**提供详细测点统计时使用（不可默认选用） | 所抽检混凝土结构构件结构厚度为实测值；xxx层共抽取了xxx处混凝土结构构件结构厚度（构件数），其中符合规范共xxx处，占所检总数的xxx%；符合要求共xxx处，占所检总数的xxx%；不符合规范共xxx处，占所检总数的xxx%。 | “xxx层”填“全楼”；“处”均按**构件**数统计；百分比为**构件合格率**；三类测点按“符合规范 / 符合要求 / 不符合规范”独立统计。 |
| **类型二（不合格）- 模板3** | 有图纸，测点合格点率 ＜ 80%，且不合格测点中“符合要求”（正偏差＞+10mm）占比 ≥ 60% | 检测结果表明：所抽检混凝土结构构件结构厚度实测偏差平均值合格点率为xxx%，主要表现为实测正偏差超出规范要求，即混凝土板厚度偏厚，不会对结构安全产生不利影响。 | xxx = 测点合格点率（%） |
| **类型三（无图纸）** | 输入数据中**设计值字段为“/”**，或明确标注“无图纸” | 所检混凝土结构构件结构厚度实测偏差为xxxmm~xxxmm，详见表xxx。 | “xxxmm~xxxmm”为全楼所有测点“实测偏差平均值”的最小值~最大值，每个数值带单位“mm”；“表xxx”中的“xxx”取输入数据来源的表头序号（如“表1”“表2”），若输入未提供表头序号则默认填写“表1”。 |

**模板选用优先级（自上而下）**：

1. 若设计值字段为“/”或明确标注“无图纸” → **类型三**。
2. 有图纸，且测点合格点率 ≥ 80% → **类型一**。
3. 有图纸，且测点合格点率 ＜ 80%：
   - 若不合格测点中“符合要求”（正偏差＞+10mm）占比 ≥ 60% → **模板3**。
   - 否则，默认使用**模板1**。
   - **仅当用户明确要求输出详细测点统计时**，才使用**模板2**（此时结论表述更换为模板2内容，但整体判定仍基于测点合格点率）。

## 四、执行步骤

**步骤1：数据整理**
- 输入必须包含：`楼层`、`构件编号`、`测点编号`（可选）、`合格判断结果`（符合规范/符合要求/不符合规范）、`实测偏差平均值`（该测点已有字段数值），以及设计厚度值（有图纸时）。
- 按楼层分组，统计：
  - 总测点数 = 所有测点记录条数
  - 总构件数 = 去重后的构件编号个数

**步骤2：逐测点判定（直接读取，禁止二次计算）**
- 对每个测点，**直接读取**“合格判断结果”字段，禁止重新计算偏差值或验证其正确性。
- 按该字段将测点归类为“符合规范 / 符合要求 / 不符合规范”三类，独立记录。
- 异常记录格式：`XX层混凝土板-构件[编号]-测点[编号]：合格判断结果为不符合规范，实测厚度偏差不满足GB 50204-2015表8.3.2要求`

**步骤3：逐层及全楼统计（测点维度）**
- 每层测点总数、符合规范测点数、测点合格点率（保留1位小数）。
- 全楼测点总数、符合规范测点数、测点合格点率。
- 全楼实测偏差平均值 = Σ各测点“实测偏差平均值”字段数值 ÷ 总测点数（保留2位小数，直接使用已有字段，不自行计算单个偏差）。

**步骤4：三类测点详细统计（仅当需要输出模板2时）**
- 全楼符合规范测点数、符合要求测点数、不符合规范测点数，及各自占所检总数的百分比（保留1位小数）。
- 全楼构件总数、合格构件数（该构件所有测点均符合规范）、构件合格率。

**步骤5：判定整体合格性（基于测点合格点率）并选择模板**
- 按第三节规则选定模板，填充数据时严格区分“测点合格点率”与“三类测点统计”口径。

## 五、输出 JSON 格式

```json
{
  "校验概述": {
    "总测点数": 数字,
    "符合规范测点数量": 数字,
    "符合要求测点数量": 数字,
    "不符合规范测点数量": 数字,
    "全楼合格点率": 数字（保留1位小数）,
    "全楼实测偏差平均值": 数字（保留2位小数）,
    "结论类型": "类型一/类型二/类型三",
    "结论表述": "字符串（严格套用所选模板）"
  },
  "逐层校验明细": [
    {
      "楼层": "字符串",
      "楼层测点数": 数字,
      "楼层合格点率": 数字（保留1位小数）,
      "楼层实测偏差平均值": 数字（保留2位小数）,
      "异常问题": [ "..." ]
    }
  ]
}
```

- `全楼合格点率`、`楼层合格点率` 均为**测点合格点率**（仅统计符合规范测点）。
- `逐层校验明细` 仅包含存在“不符合规范”测点的楼层；全楼无“不符合规范”测点时应为空数组 `[]`。
- 若采用模板2，结论表述中的内容按三类测点口径填充，但`校验概述`中的数值字段仍然使用**测点**统计口径，不得改变。
- 若为类型三（无图纸），“符合规范测点数量 / 符合要求测点数量 / 不符合规范测点数量 / 全楼合格点率 / 全楼实测偏差平均值”字段值为 `null`，仅填充“总测点数”与“结论表述”。

## 六、关键约束（必须遵守）

1. **绝对禁止混淆两种统计口径**：整体判定及模板1/3中的“合格点率”一定是测点合格点率（仅符合规范测点）；模板2及“校验概述”分类字段一定是三类测点独立统计。
2. **模板2不得默认选用**，仅当用户明确要求时才使用。
3. **绝对禁止二次计算**：严禁计算任何偏差值或重新生成“合格判断结果”，所有统计仅依赖数据中已有的“合格判断结果”和“实测偏差平均值”字段。
4. **合格点率统计口径唯一**：仅统计“符合规范”测点，严禁将“符合要求”测点纳入合格范畴。
5. 输入数据必须包含“合格判断结果”和“实测偏差平均值”字段，否则无法执行。
6. 必须按楼层严格分组，不得合并计算；同一楼层内各测点独立判定，不得合并计算平均值。
7. 结论表述中的构件名称与检测项目固定表述为「混凝土结构构件结构厚度」，不得改写为「混凝土板构件厚度」「楼板构件厚度」等其他说法。
8. 纯 JSON 输出，无额外文字。
9. 所有数值字段为数字类型。
10. 模板文字一字不差，仅替换占位符。
11. **类型三触发条件**：输入数据中设计值字段为“/”或明确标注“无图纸”时启用，此时结论表述中的表号取自输入数据来源的表头序号（若输入未提供则默认“表1”）。

## 七、示例

- 总测点数 = 20，符合规范测点 = 15，测点合格点率 = 75.0% ＜ 80%，不合格测点中“符合要求”（正偏差）占比 = 0%，选用模板1。
- 结论表述：`所检混凝土结构构件结构厚度实测偏差平均值合格点率为75.0%，不符合《混凝土结构工程施工质量验收规范》GB 50204-2015第3.0.4条之规定。`
- 全楼实测偏差平均值 = 9.25mm。
- 若用户要求模板2，则填充：`所抽检混凝土结构构件结构厚度为实测值；全楼共抽取了10处混凝土结构构件结构厚度（构件数），其中符合规范共7处，占所检总数的70.0%；符合要求共0处，占所检总数的0.0%；不符合规范共3处，占所检总数的30.0%。`
- 若设计值字段为“/”且无图纸，则输出类型三，结论表述为：`所检混凝土结构构件结构厚度实测偏差为-3mm~28mm，详见表1。`
