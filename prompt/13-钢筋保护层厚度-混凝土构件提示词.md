# 钢筋保护层厚度-混凝土构件提示词

> **统一表述规范**：构件名称统一写为「混凝土梁 / 混凝土板 / 混凝土柱 / 混凝土剪力墙 / 混凝土基础」，存在多种构件类型时统一写为「混凝土构件」；结论类型统一为「类型一（合格）/ 类型二（不合格）/ 类型三（无图纸）」；结论字段统一为「结论表述」。

## 一、任务目标

依据《混凝土结构工程施工质量验收规范》GB 50204-2015 附录E（结构实体钢筋保护层厚度检验），对提供的混凝土构件钢筋保护层厚度检测数据**仅进行全楼综合统计判定**，无需按楼层分组、逐构件校验。**合格点率直接取自输入数据中已提供的“合格点率”字段**，不再自行计算；仅需独立判定是否存在偏差超限（允许偏差的1.5倍），并按下方结论模板生成校验概述。

## 二、规范依据与校验标准

1. **核心检测依据**《混凝土结构工程施工质量验收规范》GB 50204-2015：
   - 第E.0.4条（结构实体检验）：规定检验方法、抽样数量、合格判定标准。
   - 第E.0.5条（合格判定）：双重判定标准。
     > 当全部钢筋保护层厚度检验的合格点率为90%及以上时，可判为合格；当合格点率小于90%但不小于80%时，可再抽取相同数量的构件进行检验；当按两次抽样总和计算的合格点率为90%及以上时，仍可判为合格；每次抽样检验结果中不合格点的最大偏差均不应大于规范允许偏差的1.5倍。
   - 允许偏差（混凝土梁构件、混凝土板构件）：
     - 混凝土梁构件：+10mm，-7mm（混凝土柱构件参照混凝土梁构件或设计要求）。
     - 混凝土板构件：+8mm，-5mm（混凝土剪力墙参照混凝土板构件或设计要求）。
   - 允许偏差的1.5倍（一票否决限值）：
     - 混凝土梁构件、混凝土柱构件：正偏差＞+15mm，负偏差＜-10.5mm。
     - 混凝土板构件、混凝土剪力墙构件：正偏差＞+12mm，负偏差＜-7.5mm。
2. **设计施工图（结构图纸）**：基准值来源为结构设计总说明明确的各类构件保护层最小厚度（如梁25mm、板15mm等）。

> **备注**：按 GB 50204-2015 第E.0.5条，合格点率小于90%但不小于80%时应再抽取相同数量的构件进行检验；本提示词不进行第二次抽样，直接按现有数据判定，并在结论表述中如实填写合格点率。

## 三、结论模板及其适用规则

| 结论类型 | 适用条件 | 必须逐字套用的结论表述 |
| :-- | :-- | :-- |
| **类型一（合格）** | 无偏差超限，且合格点率 ≥ 90% | 所检{构件}构件受力钢筋保护层厚度实测偏差值合格点率为xxx%，符合《混凝土结构工程施工质量验收规范》GB 50204-2015第E.0.5条之规定。 |
| **类型二（不合格）- 情形1（合格点率不达标）** | 合格点率 ＜ 90%，且无偏差超限 | 所检{构件}构件受力钢筋保护层厚度实测偏差值合格点率为xxx%，不符合《混凝土结构工程施工质量验收规范》GB 50204-2015第E.0.5条之规定。 |
| **类型二（不合格）- 情形2（偏差超限，一票否决）** | 任一实测点偏差值超过允许偏差的1.5倍（混凝土梁、混凝土柱：正偏差＞+15mm 或负偏差＜-10.5mm；混凝土板、混凝土剪力墙：正偏差＞+12mm 或负偏差＜-7.5mm） | 所检{构件}构件受力钢筋保护层厚度实测偏差值合格点率为xxx%，但{构件位置}受力钢筋保护层厚度实测偏差已超过允许偏差的1.5倍，不符合《混凝土结构工程施工质量验收规范》GB 50204-2015第E.0.5条之规定。 |
| **类型三（无图纸）** | 输入数据中**设计值字段为“/”**，或明确标注“无图纸” | 由于设计值缺失，本次检测仅提供所抽检{构件}构件受力钢筋保护层厚度实测值，详见表xxx。 |

- `{构件}` 填写规则：按实际抽检对象填写「混凝土梁 / 混凝土板 / 混凝土柱 / 混凝土剪力墙」；同时存在多种构件类型时统一填「混凝土构件」。
- `{构件位置}` 填写规则：写明楼层、构件编号及测点部位（如“3层混凝土梁KL1梁底”）。
- xxx = 合格点率（直接取自输入，保留2位小数并加“%”）；表号“xxx”取输入数据来源的表头序号，未提供时默认“表1”。

**结论判定优先级（自上而下）**：**类型三（无图纸） ＞ 类型二-情形2（偏差超限） ＞ 类型二-情形1（合格点率不达标） ＞ 类型一（合格）**。

## 四、执行步骤

**步骤0：结论初步判定**
- 检查输入数据中所有“设计值(mm)”字段。若任意一行设计值为“/”或空值，则视为无图纸项目，直接判定为**类型三**，跳过后述所有步骤。

**步骤1：直接提取输入合格点率（不再计算）**
- 必须从输入数据中提取**“合格点率”**字段：
  - 若该字段存在且为有效数值（如 `"91.15%"` 或 `91.15`），则**直接采用**，作为“全楼合格点率”。
  - 若不存在或无效，则判定为“数据不足”，停止后续判定。
- 偏差超限判定（独立进行）：遍历所有“实测偏差值（mm）”字段，按构件类型对应的1.5倍限值判定：
  - 混凝土梁、混凝土柱：正偏差＞+15mm 或负偏差＜-10.5mm；
  - 混凝土板、混凝土剪力墙：正偏差＞+12mm 或负偏差＜-7.5mm；
  - 若存在超限，则一票否决为**类型二-情形2**，合格点率仍采用输入值。

**步骤2：结论判定与表述**
- 按第三节的判定优先级选定结论类型，逐字套用对应模板，填写实际构件名称、构件位置及**从输入中提取的合格点率**（保留2位小数并加“%”）。

## 五、输出 JSON 格式（仅输出JSON，不得包含其他文字）

```json
{
  "校验概述": {
    "总测点数": 数字或null,
    "合格测点数": 数字或null,
    "全楼合格点率": 数字（保留2位小数，来自输入）,
    "是否存在偏差超限": true,
    "结论类型": "类型一/类型二/类型三",
    "结论表述": "字符串（必须套用上述模板）"
  }
}
```

- `总测点数`、`合格测点数` 仅在输入提供时填写，输入未提供时为 `null`。

## 六、关键约束（必须遵守）

1. **绝对禁止自行计算合格点率**：合格点率必须直接取自输入中的“合格点率”字段，不得依据测点数重新计算。
2. **数据完整性校验**：若输入中不存在“合格点率”字段或内容无效，则判定为“数据不足”，“全楼合格点率”设为 `/`，结论类型设为“数据不足”，结论表述写“缺少合格点率字段或格式无效，无法进行合格判定。”。
3. **一票否决优先**：只要存在偏差超限（基于实测偏差值），直接判定为类型二-情形2，无需考虑合格点率大小（但仍需输出合格点率参考值）。
4. **数值类型**：全楼合格点率为数字，保留2位小数（来自输入提取）。
5. **表述严苛性**：结论表述必须逐字套用对应模板，无任何增删改动。
6. 结论表述中的构件名称一律使用「混凝土梁 / 混凝土板 / 混凝土柱 / 混凝土剪力墙 / 混凝土基础」，多类型时使用「混凝土构件」。
7. 纯 JSON 输出，不得包含其他文字说明。
8. 当设计值输入为“/”时，表示为无图纸项目。

## 七、示例

- 输入合格点率 = 91.15%，且无偏差超限，选用类型一。
- 结论表述：`所检混凝土柱构件受力钢筋保护层厚度实测偏差值合格点率为91.15%，符合《混凝土结构工程施工质量验收规范》GB 50204-2015第E.0.5条之规定。`
- 输入合格点率 = 85.00%，无偏差超限，选用类型二-情形1。
- 结论表述：`所检混凝土柱构件受力钢筋保护层厚度实测偏差值合格点率为85.00%，不符合《混凝土结构工程施工质量验收规范》GB 50204-2015第E.0.5条之规定。`
- 输入合格点率 = 95.00%，但3层混凝土梁KL1梁底实测偏差为+16mm（＞+15mm），选用类型二-情形2。
- 结论表述：`所检混凝土梁构件受力钢筋保护层厚度实测偏差值合格点率为95.00%，但3层混凝土梁KL1梁底受力钢筋保护层厚度实测偏差已超过允许偏差的1.5倍，不符合《混凝土结构工程施工质量验收规范》GB 50204-2015第E.0.5条之规定。`
- 设计值字段为“/”且无图纸，选用类型三。
- 结论表述：`由于设计值缺失，本次检测仅提供所抽检混凝土柱构件受力钢筋保护层厚度实测值，详见表1。`
