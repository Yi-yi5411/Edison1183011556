# 砖混结构主体结构质量评定规则

> 适用范围：烧结普通砖砌体为主的砖混结构主体结构现场检测与质量评定。  
> 本规则用于项目内部数据采集、计算、报告结论的统一口径；当设计文件、地方标准或现行国家标准有更严格要求时，从严执行。

## 1. 评定依据

- GB/T 50315-2011《砌体工程现场检测技术标准》
- GB 50203-2011《砌体结构工程施工质量验收规范》
- GB 50003-2011《砌体结构设计规范》
- GB 55007-2021《砌体结构通用规范》
- GB/T 5101-2017《烧结普通砖》
- JGJ/T 136-2019《贯入法检测砌筑砂浆抗压强度技术规程》
- GB 50292-2015《民用建筑可靠性鉴定标准》
- 设计文件、检测方案及地方现行标准

## 2. 评定对象和检测项目

| 检测项目 | 主要对象 | 评定对象 |
|---|---|---|
| 砖强度（回弹法） | 烧结普通砖 | 构件、批次 |
| 砌筑砂浆强度（贯入法） | 砌筑砂浆 | 构件、批次 |
| 砌体构件尺寸偏差 | 墙体、柱、构造柱等 | 构件、检验批 |
| 外观质量 | 砌体、灰缝、构造措施 | 构件、结构单元 |

砖混结构主体结构质量评定以“砖强度、砂浆强度、尺寸偏差、外观质量”为主要内容。抗震构造、圈梁、构造柱、拉结筋等涉及结构安全的项目，应按设计文件和专项检测方案另行检查，不能仅用本规则替代。

## 3. 砖强度（回弹法）

### 3.1 检测单元

- 每个构件布置 10 个测区；
- 每个测区测 5 个回弹值；
- 测区应避开明显缺陷、裂缝、含水异常和表面疏松部位；
- 每个构件、每个批次应有唯一编号，构件位置、轴号应填写完整。

### 3.2 测区计算

测区平均回弹值：

```text
R_i = (R_i1 + R_i2 + R_i3 + R_i4 + R_i5) / 5
```

测区强度换算值：

```text
f_i = 0.02 × R_i² − 0.45 × R_i + 1.25
```

> 说明：该二次式为本项目使用的现场回弹测强曲线。使用前应确认其适用性；当地区标准、专用曲线或检测方案另有规定时，应优先采用相应曲线。

### 3.3 构件计算

构件平均强度：

```text
f_comp = (f_1 + f_2 + … + f_10) / 10
```

构件平均强度保留 2 位小数，按构件编号、构件位置和轴号识别同一构件。

### 3.4 批次统计

同一批次按构件平均强度统计，不得直接用全部测区值代替构件平均值。

```text
m = (f_comp,1 + f_comp,2 + … + f_comp,n) / n
s = sqrt(Σ(f_comp,i − m)² / (n − 1))
δ = s / m
f_std = m − 1.8s
```

其中：

- `m`：批次平均值；
- `s`：样本标准差；
- `δ`：变异系数；
- `f_std`：强度标准值；
- `n`：参与评定的构件数。

本规则对应表格中的“方差”列采用离差平方和：

```text
Σ(f_comp,i − m)²
```

标准差仍按样本标准差 `n−1` 计算。

### 3.5 砖强度等级评定

| 等级 | 平均值下限 | 强度标准值下限 | 最小值下限 |
|---|---:|---:|---:|
| MU30 | 30.0 | 23.0 | 26.0 |
| MU25 | 25.0 | 19.0 | 21.0 |
| MU20 | 20.0 | 14.0 | 16.0 |
| MU15 | 15.0 | 10.0 | 12.0 |
| MU10 | 10.0 | 6.5 | 7.5 |

评定规则：

1. `δ ≤ 0.21` 时，同时满足“平均值、强度标准值、最小值”三项要求；
2. `δ > 0.21` 时，同时满足“平均值、最小值”两项要求；
3. 从 MU30 向下逐级判定，取满足要求的最高等级；
4. 最小值取该批次全部测区强度换算值的最小值；
5. 不满足 MU10 时，评定为“不满足 MU10”。

### 3.6 砖强度合格判定

- 有设计强度等级时：评定等级不低于设计等级，判“满足设计要求”；低于设计等级，判“不满足设计要求”。
- 无设计等级时：只报告评定等级，结论写“本次检测砖强度评定为 MU××”，不作设计符合性判定。
- 构件数少于 10 个时，不具备批评定条件，应按单个构件或实际抽样范围给出检测结果，并注明批量代表性限制。

## 4. 砌筑砂浆强度（贯入法）

### 4.1 检测与计算

- 每个构件布置 3 个贯入测点；
- 记录测点1～测点3的贯入深度；
- 平均贯入深度：

```text
d = (d_1 + d_2 + d_3) / 3
```

- 砂浆强度换算值按 JGJ/T 136-2019 及所用测强曲线确定；
- 构件砂浆强度代表值按该构件各测区换算值确定。

### 4.2 合格判定

单构件：

```text
砂浆强度换算值 ≥ 设计要求值 → 符合要求
砂浆强度换算值 < 设计要求值 → 不符合要求
```

批次：

- 参与评定的构件均应满足设计要求；
- 任一构件不满足时，该批次判“不符合要求”；
- 对不合格构件应查明原因，并按检测方案扩大检测或进行可靠性鉴定。

当设计未提出明确砂浆强度要求时，应结合设计图纸、历史资料和结构现状确定评定基准，不得用无依据的默认值代替设计要求。

## 5. 砌体构件尺寸偏差

### 5.1 检测方法

每个构件或检测部位测量 3 个实测值，计算平均值和偏差：

```text
平均值 = (实测值1 + 实测值2 + 实测值3) / 3
偏差 = 平均值 − 设计值
```

偏差应带符号记录，正负号表示实际尺寸相对设计值的增大或减小。

### 5.2 常用允许偏差

以下为砖砌体工程常用允许偏差，具体以设计文件和 GB 50203 现行规定为准：

| 检查项目 | 允许偏差（mm） |
|---|---:|
| 轴线位移 | 10 |
| 每层垂直度 | 5 |
| 全高垂直度（H≤10m） | 20 |
| 全高垂直度（H＞10m） | 30 |
| 表面平整度（清水墙） | 5 |
| 表面平整度（混水墙） | 8 |
| 水平灰缝平直度（清水墙） | 7 |
| 水平灰缝平直度（混水墙） | 10 |
| 门窗洞口高、宽 | ±5 |
| 外墙上下窗口偏移 | 20 |

### 5.3 合格判定

- 一般项目合格点率不应低于 80%；
- 不合格点的最大偏差不应大于允许偏差的 1.5 倍；
- 不合格点不得连续集中，且不得影响结构安全和使用功能；
- 超出上述要求时，应扩大检测；仍不满足时，应进行结构复核或可靠性鉴定。

## 6. 外观质量

重点检查：

- 墙体裂缝：位置、长度、宽度、走向、是否贯通；
- 灰缝质量：饱满度、厚度、平直度、是否存在透明缝、瞎缝；
- 组砌方式：是否存在通缝、包心砌法、严重错缝；
- 构造措施：圈梁、构造柱、拉结筋、马牙槎、预留洞口等是否符合设计；
- 墙体渗漏、空鼓、酥碱、风化、变形等缺陷。

评定原则：

- 一般外观缺陷且不影响结构安全时，可判“基本符合”，并要求处理；
- 出现贯通裂缝、明显结构裂缝、严重变形、构造措施缺失等影响结构安全的问题时，不得直接判合格，应进行可靠性鉴定或专项复核；
- 裂缝宽度仅作为记录指标，不能脱离裂缝性质、位置和结构影响单独判定。

## 7. 综合评定

### 7.1 单项目评定

| 项目 | 合格条件 |
|---|---|
| 砖强度 | 评定等级不低于设计等级；无设计等级时报告评定等级 |
| 砂浆强度 | 构件及批次满足设计要求 |
| 尺寸偏差 | 合格点率、最大偏差和连续性满足要求 |
| 外观质量 | 无影响结构安全和使用功能的严重缺陷 |

### 7.2 结构单元综合结论

- 全部必检项目合格：结论为“该结构单元主体结构质量满足设计要求”；
- 任一必检项目不合格：结论为“该结构单元主体结构质量不满足设计要求”，并应提出复核、补强或可靠性鉴定建议；
- 资料不完整、抽样不足或检测数据异常：结论为“不具备评定条件”，不得直接下合格结论。

### 7.3 报告结论建议表述

满足要求时：

```text
经检测，该工程砖强度评定为 MU××，砌筑砂浆强度满足设计要求，
砌体构件尺寸偏差及外观质量符合设计文件和现行标准要求。
综合评定：该结构单元主体结构质量满足设计要求。
```

不满足要求时：

```text
经检测，该工程××项目不满足设计文件和现行标准要求。
综合评定：该结构单元主体结构质量不满足设计要求，
建议进行结构复核、补强处理或可靠性鉴定。
```

## 8. 数据完整性要求

出现下列情况之一时，应暂缓评定：

- 构件编号、位置、轴号无法对应；
- 测区数量不足或回弹值缺失；
- 砂浆强度换算缺少依据；
- 尺寸偏差缺少设计值；
- 外观检查记录缺少裂缝位置、宽度和走向；
- 检测批次与设计图纸、施工资料无法对应。

## 9. 使用说明

1. 本规则是项目内部评定口径，不替代现行国家标准、地方标准和设计文件。
2. 砖回弹二次式必须与所用检测设备、砖材类型和地区测强曲线匹配；更换砖种或检测设备时应重新验证。
3. 涉及结构安全、抗震构造和承载力的问题，应转入可靠性鉴定或结构复核，不能仅凭现场检测数据直接判定。
4. 报告出具前应核对原始记录、计算过程、评定等级和结论表述的一致性。
