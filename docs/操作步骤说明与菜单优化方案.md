## 一、各检测功能操作步骤说明（预置文案）

以下文案按“检测项目”维度编写，可直接预置到右侧“操作步骤说明”面板。带构件的检测项目，各构件共用同一份说明；面板实际以 `sheet_key`（如 `回弹法检测（梁）`）保存，落库时按基础项目名展开即可。

### 1. 混凝土抗压强度检测

#### 回弹法检测（梁 / 墙 / 柱 / 基础）

```
1. 确认构件类型（梁/墙/柱/基础）并核对设计强度等级。
2. 每个构件按检测方案布置测区，依次填写：楼栋、构件编号、构件位置及名称、轴线、楼层、构件类型、设计强度等级、测区数。
3. 将各测区回弹值（或测区代表值）填入“测区1～测区10”。
4. “平均回弹值、碳化深度(mm)、强度推定值(MPa)”按检测记录或仪器数据填写。
5. 本模块后续支持从外部检测数据导入生成Excel，当前可先手工录入或使用复制粘贴。
6. 全部填写完成后导出Excel复核。
```

#### 钻芯法检测（梁 / 柱 / 剪力墙 / 基础）

```
1. 勾选构件时，在参数对话框中设置：楼栋名称、构件数量、芯样数量/构件、芯样编号起始、设计强度等级、芯样直径。
2. 系统自动生成表格并计算截面积；随后补录：构件位置及名称、轴线编号、测试荷载(kN)。
3. 测试强度(MPa) = 测试荷载(kN) × 1000 ÷ 截面积(mm²)，系统自动计算。
4. 推定值(MPa) 取同一构件各芯样测试强度的最小值，系统自动计算。
5. 全部录入后，按 Ctrl+F9 或菜单“数据/工具 → 批推定计算（钻芯法）”生成批评定值。
6. 需要删除某一构件时，使用右键菜单或工具栏“删除构件”逐组删除。
```

#### 回弹钻芯修正法检测（梁 / 柱 / 板 / 墙 / 基础）

```
1. 勾选时设置：楼栋、批次数量、每批构件编号数量、每构件钻芯测区数量、设计强度等级、芯样直径。
2. 系统按“批次 → 构件 → 钻芯测区”生成表结构；补录：构件位置及名称、构件轴线编号、钻芯测区、测试荷载(kN)。
3. 截面积、测试强度自动计算；批次芯样强度均值自动汇总。
4. 导出前核对批次芯样强度均值与设计强度等级的判定结果。
```

### 2. 钢筋配置

#### 剪力墙构件钢筋间距检测

```
1. 填写：楼栋、构件位置及名称、轴线编号、方向(垂直/水平)、设计值。
2. 每个测点录入“实测值1～实测值6”。
3. 系统自动计算：实测值平均值、偏差值1～6、偏差值平均值。
4. 系统按允许偏差 ±10mm 自动计算“合格点率”和“合格/不合格”。
5. 轴线编号可两行填一次，系统会自动合并相邻两行的轴线列。
```

#### 现浇板钢筋间距检测

```
1. 填写：楼栋、构件位置及名称、轴线编号、方向(竖向/横向)、设计值。

3. 系统自动计算：实测值平均值、偏差值1～6、偏差值平均值。
4. 系统按允许偏差 ±10mm 自动计算“合格点率”和“合格/不合格”。
5. 轴线编号可两行填一次，系统会自动合并相邻两行的轴线列。
```

#### 梁构件底排受力钢筋根数检测

```

2. 录入：设计根数(梁底跨中底排)、实测根数(梁底跨中底排)。
3. 在“合格/不合格”列填写判定结果。
```

#### 柱构件主要受力钢筋根数检测

```
2. 录入：设计根数-b、设计根数-h、实测根数-b、实测根数-h。
```

#### 剪力墙钢筋根数检测

### 5. 化学植筋锚固承载力检测（柱 / 剪力墙）

```
1. 填写：楼栋、序号、构件名称、构件轴线编号、钢筋牌号/植筋规格、公称直径(mm)。
2. 录入：检测荷载(kN)、持荷2min内荷载值降低率（可填写 5% 或 0.05）。
```

## 二、预置说明的落库/插入方案

当前右侧面板由 `NotesPanel` 管理，内部是 `{sheet_key: 说明文本}`，默认为空。建议增加“默认说明字典”，只在面板首次初始化时作为底稿载入，用户编辑后仍保存为用户自定义内容。

建议新增一个数据模块，例如 `report_generator/framework/models/operation_notes.py`：

```python
DEFAULT_OPERATION_NOTES = {
    "回弹法检测": "...",           # 与上文对应
    "钻芯法检测": "...",
    "回弹钻芯修正法检测": "...",
    "剪力墙构件钢筋间距检测": "...",
    "现浇板钢筋间距检测": "...",
    "梁构件底排受力钢筋根数检测": "...",
    "柱构件主要受力钢筋根数检测": "...",
    "剪力墙钢筋根数检测": "...",
    "楼板构件厚度检测": "...",
    "剪力墙厚度检测": "...",
    "混凝土梁结构尺寸检测": "...",
    "混凝土柱结构尺寸检测": "...",
    "混凝土梁保护层厚度检测": "...",
    "混凝土柱保护层厚度检测": "...",
    "剪力墙保护层厚度检测": "...",
    "混凝土板保护层厚度检测": "...",
    "化学植筋锚固承载力检测": "...",
    "碳化深度": "...",
}
```

按 `DETECTION_DATA` 展开成面板可用的全量键：

```python
def build_default_sheet_notes(detection_data, default_notes):
    out = {}
    for items in detection_data.values():
        for item, comps in items.items():
            note = default_notes.get(item, "")
            if comps:
                for comp in comps:
                    out[f"{item}（{comp}）"] = note
            else:
                out[item] = note
    return out
```

启动时调用：

```python
self.notes_panel.set_notes(build_default_sheet_notes(DETECTION_DATA, DEFAULT_OPERATION_NOTES))
```

这样 `回弹法检测（梁/墙/柱/基础）` 四个工作表会自动显示同一份回弹法说明，且保存/加载项目时仍沿用现有 `operation_notes` 序列化逻辑，无需改动保存机制。

## 三、菜单栏优化建议

### 现状问题

- 菜单栏目前只有“工具”和“数字格式”两项，大量功能堆在工具栏，层级不清晰。
- 没有“文件、编辑、插入、格式、视图、帮助”等常用分组。
- 部分操作只藏在右键菜单里，新用户不好发现。
- 工具栏按钮过多，视觉和认知负担较重。

### 建议菜单结构

#### 文件(&F)

- 导出Excel...（Ctrl+E）
- 保存项目（Ctrl+Shift+S）
- 加载项目...（Ctrl+Shift+O）
- 分隔线
- 导入外部数据（回弹法）...（预留，暂不实现）
- 分隔线
- 退出（Ctrl+Q）

#### 编辑(&E)

- 撤销（Ctrl+Z）
- 重做（Ctrl+Y）
- 分隔线
- 剪切（Ctrl+X）
- 复制（Ctrl+C）
- 粘贴（Ctrl+V）
- 清除内容（Delete）
- 分隔线
- 查找替换（Ctrl+H）
- 删除当前工作表

#### 插入(&I)

- 上方插入行（Ctrl+Shift+I）
- 下方插入行（Ctrl+Shift+K）
- 删除行（Ctrl+Shift+D）
- 批量插入行（Ctrl+Shift+N）
- 分隔线
- 合并居中（Ctrl+M）
- 取消合并（Ctrl+Shift+M）

#### 格式(&O)

- 对齐方式 ▸ 左对齐 / 居中 / 右对齐
- 字体 ▸ 加粗 / 斜体 / 下划线 / 字号+ / 字号-
- 字体颜色
- 背景颜色
- 边框 ▸ 全部边框 / 仅外框 / 仅内框 / 上边框 / 下边框 / 左边框 / 右边框 / 无边框
- 数字格式 ▸ 常规 / 整数 / 两位小数 / 百分比 / 千分位
- 格式刷 ▸ 复制格式 / 粘贴格式
- 分隔线
- 设置行高
- 设置列宽
- 批量调整行高

#### 数据/工具(&T)

- 批推定计算（钻芯法）（Ctrl+F9）
- 删除构件（Ctrl+Shift+Delete）
- 分隔线
- 自动求和（Alt+=）
- 快速汇总 ▸ 平均值 / 最大值 / 最小值
- 批量填充（Ctrl+D）
- 批量修改

#### 视图(&V)

- 冻结窗格
- 全选检测项目
- 全不选检测项目
- 分隔线
- 显示/隐藏“操作步骤说明”面板（建议新增）

#### 帮助(&H)

- 操作说明
- 快捷键说明
- 关于

### 工具栏精简建议

菜单栏补齐后，工具栏只保留高频操作，避免与菜单重复：

- 文件：导出Excel、保存项目、加载项目
- 编辑：撤销、重做、查找替换
- 格式：合并居中、取消合并、加粗、斜体、下划线
- 数据：批推定计算、自动求和

其他低频操作统一放到菜单，界面会更简洁、更接近 Excel 的交互习惯。

### 建议实现方式

把菜单也改为数据驱动，沿用当前右键菜单的 `_build_menu_entries` 思路，新增一个 `MENUBAR_STRUCTURE` 配置，并在 `_build_menubar` 中按配置生成菜单与快捷键。这样后续调整菜单只需改配置，不需要在 UI 代码里散落 `addMenu`/`addAction`。

## 四、回弹法外部数据导入预留设计

### 目标

回弹法记录由外部来源（检测仪器导出文件、实验室表格等）导入后，直接变成系统内的 Excel 格式，减少手工录入。

### 建议数据契约

导入文件支持 `.xlsx` / `.csv`，列名应与回弹法列头匹配：

- 楼栋
- 构件编号
- 构件位置及名称
- 轴线
- 楼层
- 构件类型
- 设计强度等级
- 测区数
- 测区1～测区10
- 平均回弹值
- 碳化深度(mm)
- 强度推定值(MPa)

### 建议流程

1. 在“文件”菜单点击“导入外部数据（回弹法）...”。
2. 选择外部 Excel/CSV 文件。
3. 弹出“字段映射 + 数据预览”对话框，自动按列名匹配，允许手动调整。
4. 校验必填列、构件类型、数值范围、设计强度等级格式。
5. 选择“追加到当前工作表”或“替换当前工作表”。
6. 导入后自动计算可推导列，并保留到当前回弹法工作表。

### 后续实现注意点

- 仅先做回弹法导入，不影响钻芯法、保护层等其他模块。
- 使用项目自带 `report_generator/libs/openpyxl` 读取，避免新增依赖。
- 导入时保留用户已填的“操作步骤说明”，不要覆盖。
- 后续如果其他模块也要导入，可抽象成统一的“外部数据导入”插件接口。
