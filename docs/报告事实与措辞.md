# 报告事实与措辞（P5）

报告生成拆成两层，**数值与句子分开**：

| 层 | 模块 | 内容 | 谁可以改 |
|---|---|---|---|
| 事实 | `report_generator/utils/report_facts.py` | 抬头、逐项列/行/参数、评定结论与统计、规范清单、设备、模板、告警 | 只能由数据与评定引擎产生 |
| 措辞 | 同上（`narrative` 底稿）+ `report_render.py` | 工程概况、检测依据清单、结论句 | 智能体可改写文字，不得新增数值 |

## 事实包（`report.facts/1`）

`GET /api/report/facts`（MCP：`report_facts`）返回：

```jsonc
{
  "schema": "report.facts/1",
  "project": { "project_name": "...", "report_info": { /* 抬头字段 */ } },
  "items": [{
    "sheet_key": "剪力墙厚度检测", "base_item": "...", "component": "",
    "columns": ["..."], "rows": [["..."]], "rows_filled": 2,
    "params": {}, "has_template": true, "table_no": "5.1",
    "assessment": { "ok": true, "conclusion_type": "类型一",
                    "conclusion": "...", "summary": {}, "template": "...", "data": {} },
    "conclusion_text": "...", "narrative": ["方法/抽样说明段落…"]
  }],
  "equipment": [{ "设备名称": "...", "设备分类编号": "...", "检定证书编号": "..." }],
  "standards": ["《混凝土结构工程施工质量验收规范》GB 50204-2015"],
  "template": { "id": "...", "name": "标准检测报告模板" },
  "stats": { "items": 1, "rendered_tables": 1, "assessed": 1, "conclusions": 1, "rows": 2 },
  "narrative": {
    "overview": "确定性工程概况",
    "basis": ["确定性依据清单"],
    "conclusions": ["3.1、带编号的结论句"]
  },
  "conclusions": [{ "sheet_key": "...", "table_no": "5.1", "text": "...", "sentence": "3.1、..." }],
  "warnings": ["剪力墙厚度检测 尚未评定，结论句按原始数据生成"]
}
```

- `table_no` 只分配给**有数据且能匹配结果表模板**的项，与正文 `5.x` 一致；
- 结论句编号（`1.1、` `2.1、` `3.1、` …）与正文同一套规则（`report_chapters.next_conclusion_no`）；
- 同一输入两次构建除 `generated_at` 外完全一致（有测试守）。

## 渲染

`POST /api/report/render`（MCP：`render_report`，需 `confirm=true`）：

```json
{
  "narrative": {
    "overview": "本工程为……，本次检测……。",
    "basis": ["《混凝土结构工程施工质量验收规范》GB 50204-2015"],
    "conclusions": ["3.1、经检测，所检剪力墙厚度全部合格。"]
  },
  "template_id": "可选",
  "output_path": "可选"
}
```

- 只接受上述三个键，其它键被忽略（`clean_narrative` 白名单）；
- `conclusions` 必须保留编号前缀，渲染器原样写入「六、检测结论」；
- 渲染走 `utils.report_render.render_from_facts` → `word_report.generate_report(narrative=...)`，全程不调用模型；
- 结果照常写入记录库（`report_records`），返回 `record_id` 与 `applied_narrative`。
