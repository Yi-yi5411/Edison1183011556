# 项目结构

## 顶层

```text
structural_inspection/
├── report_generator/      业务层（桌面 Qt 应用 + 评定/报告/存储/规则）
│   ├── framework/         五层分离：ui / engine / models / services
│   ├── modules/           17 个检测项目插件（含 plugin.json manifest）
│   ├── utils/             评定、报告、规范、记录、设备、模板等纯逻辑
│   ├── structural_items/  manifest 注册表 / 技能导出 / 参数校验
│   └── libs/              内置 openpyxl（免 pip）
├── webapp/                Web 版
│   ├── backend/           FastAPI（路由、deps、sheet_apply、ingest、scan_jobs、request_log）
│   ├── frontend/          Vue 3 工作台（源码 + dist）
│   ├── mcp_server.py      主 MCP 服务（109 工具，stdio）
│   └── mcp_tools_extra.py 扩展工具（58 个）
├── cad_agent/             AutoCAD/探索者：drawing.py + mcp_server.py（12 工具）
├── integrations/yjk/      盈建科：model.py（脚本生成）+ bridge.py + mcp_server.py（4 工具）
├── desktop/               桌面端独立套件（登录 login/login_launcher、主页 home_menu、账号库 auth_db + auth.db、图标、种子 SQL）
├── tests/                 回归测试（23 套件）；legacy/ 为桌面端旧冒烟
├── scripts/               check.ps1 / release.ps1
├── config/structural.toml 唯一配置（版本/端口/DSH/CAD/YJK）
├── docs/                  架构与业务文档；manual/ 用户手册；references/ 官方资料
├── prompt/                13 份评定提示词
├── report_template/       报告章节模板
├── data/                  运行时数据（项目/记录库/模板/日志/审计）；samples/ 示例文件
├── _archive/              归档：debug/ 调试输出、models/ 模型文件、references/ 压缩资料
└── tests/, tools/, manual_assets/ …
```

## 根目录文件

| 文件 | 用途 |
|---|---|
| `run.py` / `run_app.bat` | 桌面版外部入口（薄壳 → `desktop.login_launcher`） |
| `desktop/` | 桌面端独立套件：`login.py` / `login_launcher.py` / `home_menu.py` / `auth_db.py` + `auth.db` / 种子 SQL / `app.ico` |
| `report_generator.spec` / `build.bat` / `compress.bat` | PyInstaller 打包（入口 `report_generator/main.py`；产物在 `build/`、`dist/`，不入库） |
| `install.ps1` / `start-backend.ps1` | 环境检查 / 启动 Web 后端 |
| `scripts/check.ps1` / `scripts/release.ps1` | 一键自检 / 版本发布 |
| `README.md` / `CHANGELOG.md` / `requirements*.txt` | 说明、变更记录、依赖 |

> 桌面端实现全部在 `desktop/`；根目录只保留外部入口（`run.py`、`run_app.bat`）与打包入口
> （`report_generator.spec`、`build.bat`）。`report_generator/main.py` 导入 `desktop.login_launcher`，
> 打包时 `desktop` 作为包收集，auth.db 与种子 SQL 放到 `_MEIPASS` 根目录。

## 分层与依赖方向

```text
DSH（智能体/会话/审批）
  ├─ MCP: structural_inspection → webapp/mcp_server.py → HTTP → webapp/backend → report_generator
  ├─ MCP: autocad              → cad_agent/mcp_server.py → AutoCAD COM / DXF
  └─ MCP: yjk                  → integrations/yjk/mcp_server.py → 盈建科 Python 3.10 → YJKAPI

Vue 工作台 → webapp/backend（只做编辑、评定、浏览，不做智能体对话）
```

禁止方向：业务层（report_generator）不得 import FastAPI / MCP；主程序不得 import YJKAPI。

## 放置约定

| 要加什么 | 放哪里 |
|---|---|
| 新检测项目 | `report_generator/modules/<id>/` + `plugin.json`（生成：`python -m tools.build_manifests`） |
| 新 MCP 工具 | `webapp/mcp_tools_extra.py`（或 `mcp_server.py` 基础表） |
| 新后端接口 | `webapp/backend/routers/`，业务逻辑下沉 `report_generator` |
| 新前端页面 | `webapp/frontend/src/views/` + 路由 + `api/index.ts` |
| 桌面端功能 | `desktop/`（登录/主页/账号库）；共享业务逻辑仍放 `report_generator/` |
| 新测试 | `tests/test_<主题>.py`，用 `_harness.bootstrap()` 与 `Results`；加进 `scripts/check.ps1` |
| 新文档 | `docs/`；用户手册 `docs/manual/`；外部资料 `docs/references/` |
| 示例输入/工程 | `data/samples/`（如回弹记录 .doc、钻芯法测试 .json） |
| 临时脚本/调试输出 | `_archive/`（不入库），不要放根目录 |

## 测试

- 统一在 `tests/`，每个脚本自带 `ROOT = 上一级` 引导；
- `scripts/check.ps1` 跑 23 套件 ×（3.8 + 3.14）、manifest 校验、工具面计数、目录卫生；
- `tests/legacy/` 是桌面端旧冒烟（需要 PyQt5 / 会改真实工程），不进入自检。
