# 评定规则覆盖

实现位置：

- 规则清单：`report_generator/utils/assessment_specs.py`（`ASSESSMENT_SPECS`）
- 引擎：`report_generator/utils/assessment_engine.py`
- manifest 关联：`modules/<id>/plugin.json` 的 `items[].assessment`

## 一、本次新增：填充砌体墙锚固承载力

对应原“化学植筋锚固承载力检测”（manifest 键未改，报告名称已标准化）。

### 判定口径

按原始记录模板已有的试验要求逐根判定：

1. 检测荷载 ≥ **6.0 kN**；
2. 持荷 2min 内荷载值降低率 ≤ **5%**；
3. 试验现象为“基材无裂缝、钢筋无滑移”；
4. 若“结论/试验结果”列明确写“不合格/不符合”，直接判不合格。

全部试件合格 → 类型一；存在不合格 → 类型二，并在结论中给出不合格根数与位置。

阈值在 `anchor_bearing` 规则的 `thresholds.min_load` / `max_drop` 中，可按设计文件调整。

### 实现

- spec：`id=anchor_bearing`、`family=anchor`
- 引擎：`_assess_anchor()`
- manifest：`化学植筋锚固承载力检测` 增加 `assessment.spec=anchor_bearing`
- 单测：`tests/test_assessment_smoke.py` 增加合格/不合格两例

实测当前工程 75 根：全部满足，类型一，结论为：

> 经检测，所检填充砌体墙化学植筋锚固承载力满足设计要求。

## 二、当前规则覆盖

已覆盖：

- 回弹法、回弹钻芯修正法、钻芯法；
- 梁/柱截面尺寸；
- 墙/板结构厚度；
- 梁/板/墙钢筋间距；
- 梁/柱/墙受力钢筋根数；
- 梁/柱/墙/板保护层厚度；
- 砖强度（回弹法）；
- **填充砌体墙锚固承载力**。

新增 `record_check` 逐行结论汇总族，覆盖 11 项：

**有“结论/试验结果”列，按逐行结论汇总（8 项）**

- 砌筑砂浆强度；
- 高强度螺栓扭矩系数；
- 防腐涂层厚度、防火涂层厚度；
- 钢材强度；
- 焊缝超声波探伤；
- 木构件挠度；
- 木材含水率。

**没有判定列，只记录实测值（3 项）**

- 砌体构件尺寸偏差；
- 木构件尺寸偏差；
- 木构件缺陷。

这 3 项输出类型三：“已记录实测值；因缺少设计允许值/判定依据，本次仅提供检测结果，不作合格判定。”不会伪造合格结论。

### 关于“参考规范”的边界

本机规范库目前只有 **2 本示例规范、11 条条文**（JGJ/T 23-2011、JGJ/T 384-2016），没有砌体、钢结构、木结构的规范正文。因此这批 `record_check` 规则：

- 不引用未导入的规范条号；
- 判定依据来自采集表已有的“结论/试验结果”列及其 calc_rules（如高强螺栓 0.11~0.15、木材含水率 ≤25%）；
- 没有判定列的项目明确只记录，不强行下结论。

要升级为“条文级阈值规则”，需要先把对应规范（GB 50203、GB 50205、GB 50206、GB/T 50329 等）导入规范库，再按条号补阈值和结论句式；这一步不能凭空写。

## 三、调用
