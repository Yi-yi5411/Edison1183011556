# 报告模板排版检查（2026-11-13）

检查范围：`report_template/` 下 8 个章节模板 + 30 张结果表模板；用 Word 导出 PDF 后逐页看版式，并用 `python-docx` 读取节、页眉页脚、表格网格宽度。

## 一、整体结论

模板的字体、表头重复、表线风格基本统一，但存在三类系统性问题：

1. **页眉页脚与分页**：模板页眉在生成时丢失；敬告页被套上正文页脚，页码出现 2→1→2；
2. **结果表宽度**：大部分表超过正文宽度 15.5cm，生成时被压缩，列内容换行；
3. **模板局部结构**：锚固表构件名称预合并、表题无 keep-with-next、封面多一页空白。

## 二、章节模板

| 模板 | 页数 | 发现 |
|---|---|---|
| 封面-项目名称 | 3 | 第 3 页为空白页；封面无签字线/盖章位；“注册人员（如无必备参数，删掉此行）”是模板提示 |
| 封面-首页 | 2 | 首页与目录；首页“检测依据”原为空；“检测类别”固定勾选“委托检测”；页脚“联系电话：”为空 |
| 一、工程概况 | 1 | 页眉含“报告名称/报告编号”，但生成后页眉丢失 |
| 二、主要检测依据 | 1 | 仅标题，正文由程序追加；无缩进层级 |
| 三、主要检测设备 | 1 | 表 3 只有 3 行数据，程序动态加行；设备少于模板行数时会留下空行 |
| 四、检测内容 | 1 | 仅引导段，清单由程序追加 |
| 五、检测结果概述 | 1 | 页脚缓存“第 0 页，共 2 页”，依赖 Word 更新 |
| 六、检测结论 | 1 | 公司名/日期；无签字栏 |

共性：

- 章节标题全部是 `Normal` 样式，不是 Heading，Word 导航/自动目录不可用；
- 页脚有两种模板版本：封面 `2026年07月14日生效`，正文 `2026年01月26日生效`；
- 页脚“联系电话：”始终为空；
- 封面页边距 2.5/2.1cm，正文 3.0/2.5cm，封面表格与正文表格的可用宽度不同。

生成报告时 `fit_result_table_width(table, 15.5)` 会等比压缩，但：

- 列宽被压窄后，`HRB400` 被拆成 `HRB40 / 0`；
- 模板直接打开、在线编辑或另存时仍会溢出右边距；
- 表格网格宽度和页面设置没有联动，改页边距后问题更明显。

## 四、表格局部结构

1. **锚固表构件名称预合并**：表 5.7 的“构件名称”列在模板中纵向合并了 3 个数据行，程序逐行写值后自动合并逻辑会把整列清空；已修代码，但模板本身不适合“一行一构件”的数据。
2. **表题无 keep-with-next**：结果表标题是普通段落，生成后表 5.4 标题在第 17 页底部、表体在第 18 页；表头虽设置了重复，但标题不会跟随表体。
3. **保护层表只有 6 个测点列**：实际数据有 10 个实测值，模板只能显示 6 个，其余被丢弃；需统一“6 点/10 点”采样规则或扩表。
4. **表头行高与列宽**：批次、序号、构件名称等列偏窄，表头文字换行较多；`HRB400`、`公称直径（mm）` 在压缩后断行。
5. **表头重复**已设置 `w:tblHeader`，长表跨页会重复表头；但没有“续表”字样。

## 五、生成后放大的问题

- 所有生成节的页眉为空（模板页眉未被复制），首页/正文顶部的“报告名称、报告编号”消失；
- 敬告页被套上正文页脚：敬告页显示第 2 页，首页从第 1 页开始，目录又第 2 页，页码重复/倒序；
- 封面模板第 3 页空白，靠生成时 trim 才没带出；
- 首页“检测依据”原为空（生成代码已补）、“施工单位”原为空（已加 contractor 字段）；
- 目录页码依赖 Word 更新，模板本身没有页码，Word/WPS 不可用时目录无页码。

## 六、建议优先级

| 级别 | 修复 |
|---|---|
| P0 | 复制页眉到生成节；只给正文节套正文页脚；敬告页不编号；删除封面空白页 |
| P0 | 所有结果表网格 ≤15.5cm；锚固表取消“构件名称”整列预合并；表题加 keep-with-next |
| P1 | 统一页脚模板版本/联系电话；首页检测类别可配置；保护层 6/10 点规则统一 |
| P1 | 章节标题改 Heading，目录用 TOC 域；长表加“续表” |
| P2 | 封面增加签字线/盖章位；封面注册人员提示清理；表格列宽按内容自适应 |
