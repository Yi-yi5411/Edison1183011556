# 报告预览稿

正式报告仍走 `/api/report/generate`，预检未通过会阻断。想在正式数据补齐前先看版式、表格和结论，用预览稿：

```powershell
python scripts/generate_preview.py
```

## 行为

- 不调用正式报告预检，**不占用设备**，**不写入报告生成历史**；
- 按当前工程、当前评定结果直接渲染 docx；
- 在每页页眉加红色“预览稿 · 非正式报告（未通过报告预检）”；
- 输出到 `data/previews/draft_<时间>/`，并复制一份到 `data/previews/current/`；
- 返回 `filepath`、`preview_url`、`warnings`、`skipped`。

## 当前预览

- docx：`data/previews/current/检测报告_预览稿.docx`
- pdf：`data/previews/current/检测报告_预览稿.pdf`

## 注意

预览稿仍会保留当前工程的真实缺陷，例如：

- 建设单位/施工单位为空、人员为占位值；
- 钻芯法检测（板）没有有效强度数据，表 5.2 为空；
- 砖强度检测缺结果表模板，预览时会跳过该表。

这些必须在正式报告前补齐；预览稿不能作为正式报告使用。
