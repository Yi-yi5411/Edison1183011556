# 新增检测项目：配置式扩展

普通检测项目现在可以**只写一个 JSON 配置**，不改框架代码：

```text
report_generator/modules/_configs/<项目>.json
```

启动时 `core/plugin_manager.py` 会自动发现并注册。

## 最小配置

```json
{
  "id": "demo_strength",
  "name": "演示强度检测",
  "structure_type": "其他",
  "tree_order": 100,
  "tree": {
    "演示强度检测": []
  },
  "columns": {
    "演示强度检测": ["测点编号", "实测值(MPa)", "平均值(MPa)"]
  },
  "column_types": {
    "演示强度检测": ["text", "number", "computed"]
  },
  "calc_rules": {
    "演示强度检测": {
      "2": { "type": "avg", "sources": [1], "decimals": 1 }
    }
  },
  "equipment": ["混凝土回弹仪"]
}
```

## 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一英文标识 |
| `name` | 是 | 左侧树/工作表显示名 |
| `structure_type` | 否 | 混凝土结构/钢结构/木结构/砖混结构/其他 |
| `tree_order` | 否 | 同结构类型内排序，越小越前 |
| `tree` | 否 | `{项目名: [构件...]}`；不写则由 columns 推导 |
| `columns` | 是 | `{子项目: [列头...]}` |
| `column_types` | 否 | 与 columns 对齐的列类型 |
| `calc_rules` | 否 | `{子项目: {目标列索引: 规则对象}}` |
| `equipment` | 否 | 该项目报告需要的仪器名称列表 |
| `requires_setup` | 否 | 是否弹参数设置；纯配置项目通常为 false |

`equipment` 用于报告第三章：系统会从设备库中选择**状态为“在用”**且**当天使用少于 10 次**的同名/同类仪器；每份报告对每台仪器计 1 次使用。未配置 `equipment` 的新项目在生成报告时会提示没有可用仪器。

## 计算规则

`calc_rules` 直接复用现有自动计算引擎，键为**目标列索引**（从 0 开始）。
规则对象与现有 `calc_rules.py` 相同，例如：

```json
{
  "0": { "type": "avg", "sources": [1, 2, 3], "decimals": 1 },
  "1": {
    "type": "cond_conclusion",
    "conditions": [{ "col": 0, "op": "<=", "value": 25.0 }],
    "conclusion_pass": "符合要求",
    "conclusion_fail": "不符合要求"
  }
}
```

可用 `type` 包括 `avg`、`batch_stat`、`component_stat`、`deviation`、
`pass_rate_spacing`、`conclusion`、`cond_conclusion`、`rebound_strength`、
`brick_rebound_strength` 等；具体参数由
`report_generator/framework/engine/auto_calc.py` 决定。

## 什么时候还需要 Python

以下情况仍使用 `modules/<name>/plugin.py`：

- 需要参数设置对话框、特殊建表；
- 需要专属评定规则/结论；
- 需要自定义 GUI 混入或复杂数据校验。

纯“列头 + 列类型 + 计算规则/内容”的检测项目，不需要写 Python。

## 生效方式

新增/修改 JSON 后重启后端（插件在启动时发现），左侧检测项目树和表格列即会出现。

## 更完整的契约（推荐）

配置式 JSON 只描述列头/列类型/计算规则。若要同时声明**采集参数、导入表头别名、
评定规则、报告设备、原始记录模板、技能说明**，用 `modules/<id>/plugin.json`
（`structural.item/1`，单文件即可驱动，也可与 Python 插件共存）。
详见 [检测项目MANIFEST.md](检测项目MANIFEST.md)。
