# 外部检测项目插件

## 加载目录

- 默认：`plugins/external/`
- 额外目录：`data/plugins/sources.json` 中的路径数组
- 环境变量：`STRUCTURAL_PLUGIN_DIRS`（Windows 用 `;` 分隔）

## 目录结构

```text
<plugin_root>/<plugin_id>/
  plugin.json        # 必需，schema=structural.item/1
  plugin.py          # source=python 时必需
```

## 两种插件

1. **manifest 插件**：`source: "manifest"`，只声明 columns / calc_rules / tree 等，
   不执行 Python；适合简单表格项目。
2. **Python 插件**：`source: "python"`，`plugin.py` 中实现
   `modules.base_plugin.BaseDetectionPlugin` 子类；支持自定义计算、采集参数、
   评定、报告与原始记录能力。

## 接口

- `GET /api/plugins`：全部插件，新增 `source`（builtin/external）字段
- `GET /api/plugins/external`：外部目录、加载记录、错误
- `POST /api/plugins/external/reload`：重新加载内置+外部插件
- `PUT /api/plugins/external/sources`：保存根目录并重载

## 注意事项

- Python 外部插件会执行本机代码，请只加载可信来源。
- 插件 id 与内置插件冲突时不会覆盖，加载记录会给出错误。
- 外部插件被移除后，已采集数据仍留在项目文件中，但对应树节点会消失。
